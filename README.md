# База материалов: гидроизоляция и наливные покрытия

Расчёт условий нанесения, справочник совместимости слоёв и хранилище параметров
продуктов, в котором у каждого числа есть источник и статус достоверности.

## Быстрый старт

```bash
python -m matdb dew --air 12 --rh 75 --surface 9
```

```
Точка росы:             7.7 °C
Запас над точкой росы:  +1.3 K
Влажность у поверхности:    92 %
…
Запас меньше 3 K — по общему правилу наносить нельзя.
```

Тот же расчёт в браузере, без установки и без сети: откройте
[`web/dewpoint.html`](web/dewpoint.html) — один файл, работает с телефона на
объекте. Реализация сверена с Python до 1e-9.

## Команды

| Команда | Что делает |
|---|---|
| `matdb dew` | Точка росы, запас, влажность у поверхности, влагосодержание |
| `matdb check <материал>` | Можно ли наносить этот материал в этих условиях |
| `matdb schedule <материал>` | График отверждения при фактической температуре |
| `matdb compat <верх> <низ>` | Совместимость стыка |
| `matdb gaps` | Очередь на извлечение из TDS |
| `matdb status` | Готовность карточек |

Пример с прогнозом остывания — случай, когда утром всё в допуске, а к вечеру нет:

```bash
python -m matdb check isoflex-pu-500 --air 16 --rh 70 --surface 17 \
    --moisture 3.0 --drop 6
```

Совместимость учитывает направление:

```bash
python -m matdb compat pu_1k_moisture bitumen   # нужен блокирующий слой
python -m matdb compat bitumen pu_1k_moisture   # другой вопрос, другой ответ
```

## Главное правило

**В базе нет чисел без источника.** Каждый параметр несёт статус достоверности:

```json
"substrate_temp_min_c": {
  "value": 5, "unit": "°C", "status": "tds",
  "source": "tds:isomat/isoflex-pu-500@2024-03#p2"
}
```

Голое число загрузчик отвергает с ошибкой. Причина простая: неверно извлечённое
из даташита значение выглядит ровно так же убедительно, как верное. Разница
должна быть видна коду, а не только внимательному читателю.

Статусов пять — от `verified` (человек сверил с документом и подписался) до
`unknown` (параметра нет, и это записано явно, чтобы попасть в рабочую очередь).
Подробно: [`docs/DATA_MODEL.md`](docs/DATA_MODEL.md).

Из того же правила следуют три поведения, которые выглядят как неудобство и
являются смыслом:

- **Незнание не равно разрешению.** Нет правила для пары материалов — ответ
  «нет правила», а не «совместимо». Закреплено тестом.
- **Непроведённая проверка не проходит.** Нет замера влажности основания — общий
  вердикт не «можно».
- **Пересчёт понижает доверие.** Время, пересчитанное с +20 °C на +8 °C,
  получает статус `estimated`, даже если исходное было подтверждено человеком.

## Состояние данных

Расчётная часть готова и покрыта тестами. Данные — нет: в базе заведена одна
карточка-заготовка без TDS.

```
$ python -m matdb status
Материалов: 1, правил совместимости: 27
  isoflex-pu-500: заполнено 0/23; подтверждено 0; нет ключевых: …
Пригодны для решения на объекте: 0 из 1.
```

Это честное состояние, а не незаконченная работа. Заполнение идёт по одному
документу: открыть TDS → скопировать `data/materials/_TEMPLATE.json` → заполнить
поля со ссылками на страницы → человек сверяет и подтверждает. Порядок и список
полей — в [`docs/TDS_CHECKLIST.md`](docs/TDS_CHECKLIST.md).

Правила совместимости (27 штук) заполнены на уровне химии семейств со статусом
`reference`. Они говорят, какой вопрос задать документу; ответ даёт документ.

## Границы применимости

Расчётное ядро опирается на физику и проверено по табличным значениям:
аппроксимация Магнуса в редакции Sonntag (1990), погрешность менее 0.4 % в
диапазоне −45…+60 °C. Ему можно доверять в пределах этого диапазона.

Всё остальное — нет:

- Порог 3 K над точкой росы — общее правило лакокрасочных работ, а не требование
  конкретного продукта. Подставляется, только когда TDS молчит.
- Правило Q10 (удвоение времени на каждые 10 °C) даёт порядок величины. За
  пределами 0…40 °C расчёт отказывается работать, а не экстраполирует.
- Свойства семейств — уровень учебника. Конкретный продукт может вести себя
  иначе за счёт модификаторов.
- Влажность основания не пересчитывается между шкалами: соответствия между
  весовым методом, CM и показаниями влагомера в общем виде не существует.

Расчёт не заменяет решение человека на объекте. Проверить извлечённое из TDS
число может только тот, кто держал этот материал в руках.

## Разработка

```bash
python -m pytest tests/ -q
```

Зависимостей нет — только стандартная библиотека; `pytest` нужен для тестов.
Новая карточка:

```bash
python tools/new_material.py --id <id> --name "…" --manufacturer "…" \
    --family pu_1k_moisture --role membrane
```
