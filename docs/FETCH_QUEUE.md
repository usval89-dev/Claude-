# Очередь на загрузку документов

Найденные адреса TDS. **Ни один из этих документов не открыт** — сетевая
политика окружения, в котором собирался проект, пропускает только GitHub, и
загрузка с сайтов производителей и с агрегаторов возвращает 403 на этапе
CONNECT. Адреса получены из результатов поиска (заголовки и ссылки), а не из
самих файлов.

Отсюда следует главное ограничение этого списка: **адрес найден, содержимое не
проверено.** Ссылка может вести на устаревшую редакцию, на другой вариант марки
или на страницу дистрибьютора с перепечаткой. Прежде чем извлекать числа, файл
надо открыть и убедиться, что это тот продукт и та редакция.

## Порядок работы с очередью

```bash
# 1. Скачать документ в tds/<производитель>/<продукт>.pdf (каталог в .gitignore)
# 2. Разобрать в черновик карточки
python tools/extract_tds.py tds/isomat/isoflex-pu-500.pdf \
    --id isoflex-pu-500 --revision <как напечатано в документе> --write
# 3. Сверить цитаты из отчёта с документом, проставить verified_by/verified_at
```

## ISOMAT, линейка ISOFLEX-PU 500

Линейка распадается на несколько продуктов. Это подтверждается заголовками
отдельных TDS самого производителя, и это **разные материалы с разными
параметрами** — общей карточки у них быть не может:

| Вариант | Что это | Отдельная карточка |
|---|---|---|
| ISOFLEX-PU 500 | Базовая жидкая мембрана для плоских кровель | `isoflex-pu-500` |
| ISOFLEX-PU 500 A | Ускоренного отверждения | нужна своя |
| ISOFLEX-PU 500 THIXO | Тиксотропная, для вертикальных и наклонных поверхностей | нужна своя |
| ISOFLEX-PU 500 DTL | Армированная волокном, для примыканий и узлов | нужна своя |
| ISOFLEX-PU 560 BT | Отдельный продукт линейки | нужна своя |

Времена отверждения у варианта «A» заведомо отличаются от базового — переносить
параметры между вариантами нельзя.

## Почему сюда не записаны числа

Поисковая выдача возвращала конкретные значения — расход, предел влажности,
межслойный интервал. Они не внесены ни в карточки, ни в этот файл, потому что
пересказ поисковой системы не является источником: неизвестна страница,
неизвестна редакция и неизвестно, к какому из пяти вариантов линейки относится
число. Записанное таким образом значение стало бы неотличимо от извлечённого из
документа — ровно то, против чего построена вся модель данных.

Числа появятся, когда документ будет открыт.
